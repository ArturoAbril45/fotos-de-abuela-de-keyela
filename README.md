# Album de fotos familiares - Abuela de Keyela

Este repositorio es un respaldo personal de fotografias familiares. No es un proyecto de software y no requiere instalacion ni configuracion alguna: es simplemente un archivo de fotos guardado en GitHub como copia de seguridad.

## Contenido

- 525 fotografias en formato JPG.
- 2 archivos ocultos adicionales (`.nomedia` y `.database_uuid`), generados automaticamente por la galeria del telefono de origen; no son fotografias.
- Total: 527 archivos.

## Organizacion

Todas las fotos se encuentran en una sola carpeta, sin subcarpetas. Los nombres de archivo corresponden a los nombres originales asignados por el dispositivo con el que fueron tomadas o guardadas:

- La mayoria sigue un patron numerico (por ejemplo `1000005398.jpg`).
- Algunas siguen el patron de camara `IMG_AAAAMMDD_HHMMSS_xxx@yyyy.jpg`.

## Proposito

El objetivo de este repositorio es unicamente conservar estas fotos familiares antes de formatear el equipo donde estaban guardadas. No contiene codigo, documentacion tecnica ni nada relacionado con desarrollo de software.
